# Wind Load Automation — UK (EN 1991-1-4)

Automates the retrieval of wind exposure coefficient **ce(z)** and fundamental
basic wind velocity **vb,0** for multiple building schemes using the
[EurocodeApplied wind calculator](https://eurocodeapplied.com/design/en1991/wind-peak-velocity-pressure-ireland-and-uk),
and writes the results back into an Excel workbook and a filled Wind Load
Check template per scheme.

---

## What it does

For each row in `data/schemes_input.xlsx` (one row = one building scheme):

1. **Resolves site coordinates** — uses lat/lon columns directly, or geocodes
   from a UK postcode via [postcodes.io](https://api.postcodes.io).
2. **Looks up site geodata** — OS easting/northing, full postcode, district,
   and country (single postcodes.io call).
3. **Fetches distance to sea** — scrapes [Doogal](https://www.doogal.co.uk)
   using the resolved coordinates.
4. **Fetches site elevation** — queries
   [elevation-api.eu](https://www.elevation-api.eu) (SRTM, no API key needed).
5. **Builds a scheme JSON** — formatted to match the EurocodeApplied
   SAVE/LOAD format.
6. **Runs browser automation** (Playwright + Chromium, headless):
   - Loads the JSON into the calculator.
   - Enters OS datum coordinates to obtain the correct **vb,map**.
   - Clicks CALCULATE and extracts **ce(z)** from the result page.
   - Saves a **PDF report** per scheme to `data/reports/`.
   - Downloads the result JSON back to `data/temp/` to read **vb0**.
7. **Writes all results** to `data/schemes_output.xlsx`.
8. **Populates the Wind Load Check template** — copies
   `data/STxxxx_Wind load check.xlsx` per scheme, fills the mapped cells
   (height, width, length, elevation, ce(z), vb0), and saves a filled copy
   to `data/reports/`.

## Quick start

### Option A — Portable (no system Python required)

1. Run `install_portable_local_python.bat` **once**.
   This downloads Python 3.11 embedded, installs all packages, and installs
   Playwright Chromium — all inside `current version/runtime/`.
2. Fill in your schemes in `data/schemes_input.xlsx` (see
   [Input format](#input-format) below).
3. Double-click `run_Wind_Load_UK.bat`.

### Option B — System Python

1. Ensure Python 3.9+ is installed and on your `PATH`.
2. Install dependencies:
   ```
   pip install pandas openpyxl requests playwright
   playwright install chromium
   ```
3. Fill in `data/schemes_input.xlsx`.
4. Double-click `run_Wind_Load_UK.bat`, or run directly:
   ```
   cd "current version"
   python bin/runner.py
   ```

## Input format

Open `data/schemes_input.xlsx`, sheet **Schemes**. Each row is one building:

| Column | Required | Description |
|---|---|---|
| `SchemeID` | auto | Filled automatically (1, 2, 3…) |
| `H` | ✅ | Building height (m) |
| `B` | ✅ | Building width (m) |
| `L` | ✅ | Building length (m) |
| `Latitude` + `Longitude` | one of | WGS84 decimal degrees |
| `Postcode` | one of | UK postcode (used if lat/lon absent) |

At least one of **Latitude/Longitude** or **Postcode** must be provided per row.
If only coordinates are given the postcode is reverse-geocoded automatically,
and vice versa.

## Outputs

| File | Description |
|---|---|
| `data/schemes_output.xlsx` | Full results table — ce(z), vb0, elevation, distance to sea, OS grid, postcode |
| `data/reports/scheme_N_wind_result.pdf` | PDF printout from the EurocodeApplied calculator per scheme |
| `data/reports/scheme_N_Wind_load_check.xlsx` | Filled Wind Load Check template per scheme |

---

## Resetting the data folder

To start a fresh run without leftover outputs, double-click
`data/clear_data.bat`. It will:

- Delete `schemes_output.xlsx`
- Empty `reports\` and `temp\` (folders are kept)
- Leave `schemes_input.xlsx`, `STxxxx_Wind load check.xlsx`, and
  `clear_data.bat` untouched
